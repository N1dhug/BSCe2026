HOW TO RUN PYTHON FILES IN THE TERMINAL
=======================================

1. Open a terminal in the ROOT folder of your project.

   Example project structure:

   project/
   ├── models/
   │   ├── __init__.py
   │   └── BatteryModel/
   │       ├── __init__.py
   │       ├── BatteryModel.py
   │       ├── bm_1.py
   │       └── BM2.py
   └── main.py

   Your terminal should be in:

   project/

   NOT inside:

   project/models/
   project/models/BatteryModel/


2. Activate your Python environment, if your project uses one.

   Conda:

   conda activate your_environment_name

   Windows virtual environment:

   .venv\Scripts\activate

   macOS / Linux virtual environment:

   source .venv/bin/activate


RUNNING A NORMAL PYTHON SCRIPT
------------------------------

For a standalone script in the current directory:

   python filename.py

Example:

   python main.py


RUNNING A FILE INSIDE A PYTHON PACKAGE
--------------------------------------

If the file is inside a package and uses imports such as:

   from models.BatteryModel.BatteryModel import BatteryModel

or:

   from .BatteryModel import BatteryModel

run the file as a MODULE from the PROJECT ROOT.

Example:

   python -m models.BatteryModel.bm_1

For BM2:

   python -m models.BatteryModel.bm_2


IMPORTANT
---------

When using:

   python -m

use the Python module path, NOT the filename.

Correct:

   python -m models.BatteryModel.bm_1

Incorrect:

   python -m bm_1.py

Incorrect:

   python -m models.BatteryModel.bm_1.py


WHY THE PROJECT ROOT MATTERS
----------------------------

Suppose bm_1.py contains:

   from models.BatteryModel.BatteryModel import BatteryModel

Python needs to be able to see the top-level "models" package.

Therefore, launch Python from the directory containing "models".

Correct terminal location:

   project/

Command:

   python -m models.BatteryModel.bm_1

If you instead run the command from:

   project/models/BatteryModel/

Python may fail with:

   ModuleNotFoundError: No module named 'models'


CHANGING TO THE PROJECT ROOT
----------------------------

Windows PowerShell / Command Prompt:

   cd "C:\path\to\your\project"

macOS / Linux:

   cd "/path/to/your/project"

If you are currently two folders below the project root, you can often use:

   cd ..\..

on Windows, or:

   cd ../..

on macOS / Linux.


FULL EXAMPLE
------------

Windows:

   cd "C:\path\to\your\project"
   conda activate your_environment_name
   python -m models.BatteryModel.bm_1

macOS / Linux:

   cd "/path/to/your/project"
   conda activate your_environment_name
   python -m models.BatteryModel.bm_1


PACKAGE REQUIREMENTS
--------------------

Folders used as Python packages should generally contain:

   __init__.py

Example:

   models/
   ├── __init__.py
   └── BatteryModel/
       ├── __init__.py
       ├── BatteryModel.py
       └── bm_1.py


USEFUL COMMANDS
---------------

Check the current directory:

Windows PowerShell:

   Get-Location

Windows Command Prompt:

   cd

macOS / Linux:

   pwd

Check the Python version:

   python --version

On some systems:

   python3 --version

Check which Python executable is active:

Windows:

   where python

macOS / Linux:

   which python

List installed packages:

   python -m pip list

Install a package:

   python -m pip install package_name

Install dependencies from requirements.txt:

   python -m pip install -r requirements.txt


VS CODE
-------

Open the integrated terminal:

   Ctrl + `

Select the Python interpreter:

   Ctrl + Shift + P
   Python: Select Interpreter

Choose the environment used by the project.

Also make sure the integrated terminal starts in the project root before
running package modules.


COMMON ERRORS
-------------

1. ModuleNotFoundError: No module named 'models'

   Usually means Python was started from the wrong directory.

   Move to the project root and run:

   python -m models.BatteryModel.bm_1


2. ImportError: attempted relative import with no known parent package

   Usually means a package file was run directly:

   python bm_1.py

   Instead, run it from the project root as a module:

   python -m models.BatteryModel.bm_1


3. No module named 'bm_1.py'

   Do not include ".py" when using "-m".

   Correct:

   python -m models.BatteryModel.bm_1


GENERAL RULE
------------

Standalone script:

   python file.py

Package module:

   python -m package.subpackage.module

For package modules, run the command from the project root.

# F1 — deterministic BM1: model, numerics and feasibility

This is the consolidated description of the implemented F1 work. See
[F2.md](F2.md) for the stochastic extension and [BM_REVIEW.md](BM_REVIEW.md)
for the consolidation audit. Equations below describe the code, not an
additional battery model. The independent formulas in the regression tests
are intentionally retained as independent checks rather than deduplicated.

## Model and units

The parameter list is `[U, f, g, C, k, Xi]`. State of charge $x$, baseline
$B$, demand $D$, price $U$ and flexibility $\Xi$ are normalized. With physical
capacity $C_{\mathrm{phys}}$ and fixed power scale $P_{\mathrm{scale}}$,

$$C=C_{\mathrm{phys}}/P_{\mathrm{scale}}$$

has units of time. The response and demand are

$$\delta(x,u)=\frac{2}{1+\exp[-k(f(x)+g(u))]}-1
=\tanh\!\left(\frac{k}{2}(f(x)+g(u))\right),$$

$$D(x,u,B)=B+\Xi\,\delta(x,u)
\begin{cases}1-B,&\delta\geq0,\\B,&\delta<0.\end{cases}$$

The deterministic state equation is

$$\dot X_t=\frac{D(X_t,U(t),B(t))-B(t)}{C}.$$

Assume $C>0$, $k>0$, $0\leq\Xi\leq1$, $B,U\in[0,1]$, and admissible response
functions. F2 additionally validates the canonical endpoint normalization.
`stochastic=True` in the legacy `dXdt` signature does not add Brownian noise.

The exact deterministic energy balance is

$$C(X_t-X_0)=\int_0^t(D_s-B_s)\,ds.$$

It applies to the deterministic equation; it must not be reused as a
pathwise identity without a stochastic integral in F2.

## F1-A: exact benchmark and Euler limit

For the benchmark responses $f(x)=1-2x$ and $g(u)=1-2u$,

$$\delta(x,u)=\tanh(k(1-x-u)).$$

On an interval starting at $t_0$ with constant price $u$ and baseline $B$,
set $q=1-u$ and $\gamma=1-B$ if $x_0<q$, otherwise $\gamma=B$.
The solution cannot cross its equilibrium on this constant-input interval.
Since $Y=\sinh(k(X-q))$ satisfies

$$\dot Y=-\frac{k\Xi\gamma}{C}Y,$$

the exact solution is

$$X(t)=q+\frac1k\operatorname{arsinh}\!\left[
\sinh(k(x_0-q))\exp\!\left(-\frac{k\Xi\gamma}{C}(t-t_0)\right)
\right].$$

Restart this expression at each price change. It is not an exact formula for
arbitrary PCHIP responses or time-varying baselines.

Euler–Maruyama with zero noise is ordinary explicit Euler:

$$X_{n+1}=X_n+h_n(D_n-B_n)/C.$$

Its cumulative energy residual vanishes up to arithmetic roundoff when the
integral is evaluated with those same left-endpoint increments. This is not
an assertion that a different quadrature rule yields the same residual.
The reference checks approximately first-order deterministic convergence.

## F1-B: breakpoint-aware ODE solution

`bm_1.deterministic_solver` uses `solve_ivp`. Known input discontinuities are
passed explicitly in `breakpoints`; the ODE is restarted at each one.
One-sided evaluations prevent a previous interval's final RHS call from
using the next interval's price. The state is continuous at a jump, but its
derivative and demand need not be.

`t_eval` selects returned values. `rtol`, `atol` and `max_step` control the
ODE solve. Old calls without breakpoints retain their historical behavior;
callers must supply known jumps when accurate discontinuous-input simulation
is required. Merely adding a jump to a plotted output grid is not equivalent.

## F1-C: price decisions

For fixed edges $s_0<\cdots<s_N$, there is exactly one decision $u_j$ per
interval. `input_builder.price_intervals` is right-continuous:

$$U(t)=u_j\quad(s_j\leq t<s_{j+1}),\qquad U(s_N)=u_{N-1}.$$

The number of price decisions is independent of the number of output points.
The builder retains endpoint prices outside the edge interval; the optimizer
therefore separately validates that the edges span the entire model horizon.

## F1-D: deterministic price optimization

The implemented problem is

$$\min_{\boldsymbol u\in[0,1]^N}
J_{\mathrm{det}}(\boldsymbol u),\qquad
J_{\mathrm{det}}=\int_0^T(D_t-A(t))^2\,dt.$$

The historical model API uses bounded L-BFGS-B and the shared
`tracking_error(time, demand, target)` Simpson quadrature on supplied samples.
The F1-D benchmark recovers a known two-price vector `[0.72, 0.28]` from a
target generated on that same grid. This validates the discrete benchmark;
it is neither a proof of global convexity nor a generic error estimate.

### Quadrature limitation and a BM-only alternative

Restarting the **state solver** at a jump does not make a global Simpson rule
on sampled **costs** jump-aware. The old F1 target also linearly interpolates
its sampled demand, including across a jump. Consequently its near-zero
sampled objective does not establish exact continuous-time tracking between
all samples. Those shared historical APIs are unchanged by the consolidation.

For a deterministic cost with known discontinuities, the opt-in
`deterministic_midpoint_objective` in `src/method/bm_1_stochastic_objective.py`
uses the same breakpoint-safe quadrature as F2-H, with variance set to zero.
Supply all jumps of $U$, $B$ and $A$. It returns the deterministic cost as a
`StochasticTrackingResult` with `variance == 0`; it does not silently change
`model.optimize` or the old F1 benchmark.

## F1-E: distinguish infeasibility from optimizer failure

### Price-envelope certificate

For linear responses and a physical state $x\in[0,1]$, monotonicity in price gives

$$D_{\min}(x)=B\,[1-\Xi\tanh(kx)],$$

$$D_{\max}(x)=B+\Xi(1-B)\tanh(k(1-x)).$$

For $0<B<1$, $0<\Xi\leq1$ and $|z|<1$, the required price for a requested
demand $d$ is

$$u=1-x-\frac1k\operatorname{artanh}(z),\qquad
z=\frac{d-B}{\Xi\gamma},\quad
\gamma=\begin{cases}1-B,&d\geq B,\\B,&d<B.\end{cases}$$

An implied price outside $[0,1]$ is an infeasibility certificate, independent
of any optimizer's termination flag. These inverse/envelope formulas are
specific to the linear responses. In particular the envelope must not be
interpreted as a physical bound for a state outside $[0,1]$.

### Capacity certificate

For constant target $A_0$ and baseline $B$ over duration $S$,

$$X_{\mathrm{required}}(t)=X_0+(A_0-B)(t-t_0)/C.$$

If $A_0>B$, define excess required energy

$$E_{\mathrm{excess}}=[(A_0-B)S-C(1-X_0)]_+.$$

If $A_0<B$, use

$$E_{\mathrm{excess}}=[(B-A_0)S-CX_0]_+.$$

The state bound and Cauchy–Schwarz imply the deterministic lower bound

$$J_{\mathrm{det}}\geq E_{\mathrm{excess}}^2/S.$$

This is necessary, not sufficient, for demand feasibility. Prices and response
limits may impose additional restrictions even when capacity is sufficient.
The benchmark separately exercises a forbidden-price target and a target
requiring $X(1)=1.02$.

## F1-F: regression coverage and run commands

`tests/test_bm_1_f1.py` independently checks the exact solution, Euler order,
energy balance, breakpoint handling, price-grid semantics, known-price
recovery, and the two infeasibility certificates.

Run from the repository root:

```powershell
python -B -m unittest discover -s tests -p "test_bm_1_f1.py" -v
python -B -m src.exe.run_model.bm_1.deterministic_reference
python -B -m src.exe.run_model.bm_1.optimization_reference
python -B -m src.exe.run_model.bm_1.optimization_feasibility_reference
```

The principal implementations are `src/model/base/bm.py`, `src/model/bm_1.py`,
`src/diagnostics/bm_1.py`, their validators, and the existing shared input and
objective helpers. They are not renamed or globally reformatted by this
BM-only consolidation, because WM's package imports reach several of them.

## Sources and interpretation

The model convention follows the existing F1/F2 code and Junker et al.,
*Stochastic nonlinear modelling and application of price-based energy
flexibility*, Applied Energy 275 (2020), 115096,
DOI: 10.1016/j.apenergy.2020.115096. Its flexibility parameter is called
`Xi` in this repository. The exact benchmark, inverse and capacity bounds
above are derivations for the explicitly stated special case, not formulas
claimed for arbitrary response functions in the source paper.

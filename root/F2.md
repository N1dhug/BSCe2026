# F2 — stochastic BM1, density approximations and price optimization

This consolidated note replaces the running descriptions in F2_A through F2_I
and F2_B_convergence. Earlier versions remain in Git history; obsolete module
paths are not retained as compatibility wrappers. [F1.md](F1.md) defines the common demand
map and deterministic benchmark. [BM_GUIDE.md](BM_GUIDE.md) records the audit.

The implementation is complete for the controlled reference workflow. That
is not a claim of universal solver accuracy or globally optimal pricing.

## F2-A — stochastic model contract

For deterministic inputs $U(t),B(t)$, the model is the **Itô** SDE

$$dX_t=a(t,X_t)\,dt+b(X_t)\,dW_t,$$

$$a(t,x)=\frac{D(x,U(t),B(t))-B(t)}{C},\qquad
b(x)=\sigma_Xx(1-x).$$

The existing demand function is unchanged. The diffusion routine returns the
amplitude $b$, not $b^2$, $b\sqrt{h}$ or $b/C$. In particular $\Xi=0$ removes
the demand response/drift, not the process noise. `stochastic=True` in the
legacy deterministic derivative does not simulate this SDE.

Assume $C,k>0$, $0\leq\Xi\leq1$, $\sigma_X\geq0$, $B,U,X_0\in[0,1]$ and
nonincreasing responses in $[-1,1]$ satisfying

$$f(0)=g(0)=1,\qquad f(1)=g(1)=-1.$$

The drift must have suitable state regularity, for example local Lipschitz
regularity with appropriate uniform bounds on the horizon. Random initial
states are independent of future Wiener increments. The endpoint checks in
code do **not** prove monotonicity or regularity of an arbitrary callable.

The endpoint signs give

$$a(t,0)\geq0,\quad a(t,1)\leq0,\quad b(0)=b(1)=0.$$

Under the regularity assumptions this makes the continuous interval invariant.
It does not guarantee that a finite-step EM proposal remains inside it.

### Units and energy balance

$C$ has time units and $\sigma_X$ has units time$^{-1/2}$. Changing hours to days
requires

$$t_d=t_h/24,\qquad C_d=C_h/24,\qquad
\sigma_{X,d}=\sqrt{24}\,\sigma_{X,h},$$

and a corresponding change of every input's time argument and breakpoint.
Plotting $24t$ alone is only a display conversion.

The stochastic energy identity is

$$C(X_t-X_0)=\int_0^t(D_s-B_s)\,ds+C\int_0^t b(X_s)\,dW_s.$$

The stochastic integral has zero expectation under the usual integrability
conditions; it is not zero pathwise.

### Legacy demonstrations are not references

The four-day `em_price_step` demonstration uses reflected EM from a point.
`fp_price_step` uses the historical FV-plus-Beta route, including internal
clipping/normalization and a spread-out initializer. Their masses and plots
are useful regression outputs, not a same-initial-law validation. Both remain
available because WM1 also uses the historical FP class.

## F2-B — EM reference and Brownian coupling

The controlled EM recursion is

$$X_{n+1}=X_n+a(t_n,X_n)h_n+b(X_n)\Delta W_n,\qquad
\Delta W_n\sim N(0,h_n).$$

`t_eval` selects outputs; `breakpoints` and `max_step` add internal times.
All output times are embedded in the integration grid. Thus the arguments
have distinct roles, but changing the output grid can still change the actual
numerical steps. Known price jumps must be integration boundaries.

Externally supplied Wiener increments make coupled comparisons possible:

$$\Delta W_k^{\mathrm{coarse}}=
\sum_{j=0}^{r-1}\Delta W_{rk+j}^{\mathrm{fine}}.$$

Independent paths do not give a strong-error comparison. The default controlled
reference uses `boundary="none"` and records raw violations before correction.
Observed absence of violations only concerns the simulated sample and settings.

For a suitable SDE in the asymptotic regime, EM has strong RMS order $1/2$:

$$E_h=\bigl(\mathbb E|X_T^h-X_T|^2\bigr)^{1/2}=O(h^{1/2}),\qquad
p_h=\frac{\log(E_h/E_{h/2})}{\log2}.$$

The exact benchmark is

$$X_t=\operatorname{sigmoid}(\operatorname{logit}(x_0)+\sigma W_t),$$

which, by Itô's formula, satisfies

$$dX_t=\tfrac12\sigma^2X_t(1-X_t)(1-2X_t)\,dt
+\sigma X_t(1-X_t)\,dW_t.$$

This tests the algorithm without changing BM1's drift. The BM1 experiment
instead compares successive coupled approximations; its self-convergence
slope is not an exact-solution error or a universal convergence proof.

## F2-C — pure finite-volume reference

The Fokker–Planck equation and probability flux are

$$\partial_t p=-\partial_x(ap)+\tfrac12\partial_{xx}(b^2p)
=-\partial_x\mathcal J,\qquad
\mathcal J=ap-\partial_x(\kappa p),\quad\kappa=\tfrac12b^2.$$

The derivative acts on the **complete product** $b^2p$. Replacing this by
$b^2p_{xx}$ is a different equation. Here $D$ remains demand; $\kappa$ denotes
the diffusive coefficient to avoid a notational collision.

On uniform cells of width $\Delta x$, the unknown is

$$m_i(t)\approx\int_{V_i}p(x,t)\,dx,\qquad p_i=m_i/\Delta x.$$

Upwind drift plus a centered difference of $\kappa p$ gives rates across each
interior face:

$$r_i^+=\frac{\max(a_{i+1/2},0)}{\Delta x}
+\frac{b_i^2}{2\Delta x^2},\qquad
r_{i+1}^-=\frac{\max(-a_{i+1/2},0)}{\Delta x}
+\frac{b_{i+1}^2}{2\Delta x^2}.$$

For column probabilities, $\dot m=Qm$: off-diagonal entries are nonnegative,
diagonals are minus the outgoing rates, and $\mathbf1^TQ=0$. No transitions
leave $[0,1]$, implementing zero boundary probability flux.

The reference evaluates drift at faces and diffusion at centers. Backward
Euler with coefficients frozen at the left endpoint is

$$(I-hQ_n)m^{n+1}=m^n.$$

Multiplication by $\mathbf1^T$ proves exact-arithmetic conservation. The
matrix is a nonsingular M-matrix, so its inverse is nonnegative. Together
these preserve probabilities without postprocessing. A tridiagonal Thomas
solve is used. Floating-point residuals are monitored; stability and mass
conservation alone do not establish spatial/time accuracy.

The implementation is `finite_volume_1d` inside the shared
`src/solver/finite_volume.py`. It is not moved or changed in this consolidation.
The BM wrapper requires an explicitly normalized initial mass vector.

## F2-D — common initial law and MC/FV comparison

`src/validation/bm_1/cases.py` defines the one-day reference: $B=0.3$, $C=1$ day,
$k=2$, $\Xi=1$, $\sigma_X=0.5$ day$^{-1/2}$, monotone PCHIP responses and a
price drop $0.75\to0.25$ at 12.5 h. The comparison law is

$$X_0\sim\operatorname{Beta}(20,20),\qquad
m_i(0)=F_0(x_{i+1/2})-F_0(x_{i-1/2}).$$

MC samples from that law using a stream independent of the Wiener stream.
The older controlled EM reference intentionally still starts at $X_0=0.5$.
A smooth Beta law is a reference-case choice, not a physical requirement.

MC samples are histogrammed on the FV edges. Comparison quantities include
$\mathbb E[X]$, $\operatorname{Var}(X)$, $\mathbb E[D]$ and

$$L^1=\sum_i|m_i-\widetilde m_i|,\quad
d_{\mathrm{CDF}}=\max_i\left|\sum_{j\leq i}(m_j-\widetilde m_j)\right|,$$

$$W_1^{\mathrm{grid}}=\Delta x\sum_i|F_i-\widetilde F_i|.$$

The last expression is the Wasserstein distance for equal-grid center-mass
representations, not an exact distance between unknown continuous densities.
MC uncertainty, EM time error, FV time error and FV space error are separate.
The existing single-resolution comparison does not quantify all four by
independent refinement. Agreement is evidence for this controlled problem.

## F2-E — static Beta representation

For degree $M$, the fixed continuous components are

$$\ell_j(x)=(M+1){M\choose j}x^j(1-x)^{M-j}
=\mathrm{BetaPDF}(x;j+1,M-j+1),\qquad j=0,\ldots,M.$$

The code samples them at cell centers and normalizes each sampled component
with $\Delta x\sum_i\ell_j(x_i)$. It does **not** use CDF-integrated basis
components; the Beta initial-law cell masses above do use CDF differences.

Let $\Phi_{ij}$ be the normalized sampled basis. Each FV snapshot is projected
independently:

$$c^*(t)=\arg\min_{c\geq0,\ \mathbf1^Tc=1}
\tfrac12\|\Phi c-p^{\mathrm{FV}}(t)\|_W^2,
\quad W=\Delta xI.$$

Then $H=\Phi^TW\Phi$ and $q=-\Phi^TWp$. The shared active-set QP solver is
reused. This static experiment does not propagate earlier coefficients.
The default degrees are $5,10,20,30,38$.

### Continuous-basis variance limitation

A component has mean $\mu_j=(j+1)/(M+2)$ and variance
$\mu_j(1-\mu_j)/(M+3)$. If the component index is random with weights $c_j$
and the mixture mean is $m$, total variance gives the exact identity

$$\operatorname{Var}(X)=\frac{m(1-m)}{M+3}
+\frac{M+2}{M+3}\operatorname{Var}(\mu_j)
\geq\frac{m(1-m)}{M+3}.$$

The bound need not be attainable for every mean because component means are
discrete. For the continuous initial Beta(20,20) law,
$\operatorname{Var}(X_0)=0.25/41$. At $M=20$ the centered floor is $0.25/23$;
at $M=38$, component $j=19$ is exactly Beta(20,20). Exact continuous inclusion
does not by itself imply exact equality of midpoint samples and FV cell averages.
The bound is analytical for continuous components, not an exact identity for
discretely renormalized grid moments.

## F2-F — dynamic projected mixture

The reusable BM-only implementation is now `src/method/bm_1_mixture.py`.
Each internal step starts from the current mixture, not from an FV solution:

$$\widetilde p^{n+1}=\widehat p^n+hL_h(t_n)\widehat p^n,
\qquad\widehat p^{n+1}=\Phi c^{n+1},$$

$$c^{n+1}=\arg\min_{c\geq0,\ \mathbf1^Tc=1}
\tfrac12\|\Phi c-\widetilde p^{n+1}\|_W^2.$$

The QP uses the previous feasible coefficients as a warm start. Fixed
projection matrices can be reused across candidate prices. Positivity of
the raw explicit prediction is controlled using the **sum** of outgoing
advective and diffusive rates:

$$h\,\max_i r_{\mathrm{out},i}\leq\mathrm{CFL},\qquad
\mathrm{CFL}=0.40\text{ by default}.$$

Raw and projected masses and simplex constraints are checked without
clipping or renormalization. Tiny negative floating-point residues are
reported rather than repaired. Output arrays start as NaNs, making a missed
output fail explicitly instead of exposing uninitialized memory.

The predictor reuses the legacy conservative flux, which averages drift
values at neighboring centers. Pure FV instead evaluates drift directly at
faces and uses implicit time stepping. Consequently the dynamic-versus-FV
gap also contains these discretization differences; it is not a perfectly
isolated measurement of repeated projection alone.

For the best static same-degree approximation $p_*^M$, report

$$E_{\mathrm{total}}=\|p_{\mathrm{dyn}}^M-p_{\mathrm{FV}}\|,
\quad E_{\mathrm{static}}=\|p_*^M-p_{\mathrm{FV}}\|,
\quad E_{\mathrm{gap}}=\|p_{\mathrm{dyn}}^M-p_*^M\|.$$

They obey a triangle inequality, not an additive error decomposition. Exact
static L2 minimization bounds the achievable same-space L2 error below, but
does not minimize every moment or objective error. Comparing maxima at
different times is not a pointwise decomposition.

Projection currently occurs after **every internal step**. Output times are
hard step boundaries, so changing the output grid changes the projection
schedule. A fully independent projection grid remains a possible extension;
it is not claimed as implemented.

## F2-G — conditioning and sensitivity

With weighted design matrix $A_W=\sqrt{\Delta x}\Phi$,

$$H=A_W^TA_W,\qquad \kappa_2(H)=\kappa_2(A_W)^2$$

in exact arithmetic when $A_W$ has full column rank. Forming the normal matrix
can lose its smallest singular directions in floating point. A reported
$\kappa(H)\approx10^{17}$ is not an accurate measurement of a true condition
number potentially much larger: the measured $\kappa(A_W)\approx1.48\cdot10^{11}$
at $M=38$ would square to approximately $2.2\cdot10^{22}$.

For a fixed degree and grid, **the full Hessian is independent of the target
density**. A changing density may change the active constraints and thus the
locally relevant reduced Hessian; it does not change the fixed basis overlap.

On $F=\{j:c_j>10^{-8}\}$, take $Z$ spanning $\mathbf1_F^Td_F=0$ and inspect

$$Z^TH_{FF}Z.$$

This is a fixed-active-set diagnostic, not a bound covering every possible
active-set change. F2-G also repeats static solves from a uniform feasible
start and perturbs targets by $p_\varepsilon\propto p\exp(\varepsilon r)$.
The normalization here **constructs a test input**; it is not a repair of an
evolved solver state.

Coefficient and density changes are measured separately. A full-rank basis
can have mathematically unique but numerically sensitive coefficients. The
observed sensitivity does not prove mathematical non-uniqueness. For the
fixed convex density set, exact weighted-L2 projection is nonexpansive:

$$\|P(p)-P(q)\|_W\leq\|p-q\|_W.$$

Thus sensitivity below one for represented densities is compatible with large
coefficient sensitivity. Solver tolerances can hide perturbations below their
resolution. The tested snapshots/random directions do not certify robustness
for every price, initial law, degree or dynamic perturbation.

## F2-H — expected tracking objective

For a **deterministic** target $A(t)$,

$$J(U)=\int_0^T\mathbb E[(D_t-A(t))^2]dt
=J_{\mathrm{bias}}+J_{\mathrm{variance}},$$

$$\mathbb E[(D_t-A)^2]=(\mathbb E[D_t]-A)^2+\operatorname{Var}(D_t).$$

Density evaluation uses $\mu_D=\sum_i D_i m_i$ and
$s_D=\sum_iD_i^2m_i$, hence $\operatorname{Var}(D)=s_D-\mu_D^2$.
Variance roundoff guards are distinct from probability-mass correction.
For MC, the empirical variance uses denominator $N$ so the sampled identity
is exact. Each complete simulated path has a cost

$$J^{(r)}=\sum_k w_k(D^{(r)}(\tau_k)-A(\tau_k))^2,$$

and $\operatorname{SE}(\overline J)=s_J/\sqrt N$ uses the sample standard
deviation across complete path costs. Temporal dependence within a path is
therefore retained. This SE excludes discretization error.

Midpoint quadrature splits at all supplied discontinuities:

$$\tau_k=(t_k+t_{k+1})/2,\quad w_k=t_{k+1}-t_k,
\qquad J\approx\sum_k w_k\,\mathbb E[(D_{\tau_k}-A_{\tau_k})^2].$$

`objective_max_step` and `solver_max_step` have separate roles, but solver
outputs are still embedded in their integration grids. A refinement of the
objective sampling is not automatically a pure quadrature-only experiment.
The reusable price evaluator now accepts additional known jumps in $A$ or $B$
as well as its price edges. General callable discontinuities are not inferred.

Zero demand variance recovers deterministic squared tracking with the same
quadrature. Setting $\sigma_X=0$ alone does not remove a random initial law.
The reference has $A=B=0.3$ and compares MC, pure FV and mixtures of degrees
20, 30 and 38. Close scalar costs can involve cancellation of bias and
variance errors; they need not improve monotonically with degree.

## F2-I — stochastic price optimization

For fixed edges, solve the nonlinear bounded problem

$$\min_{\boldsymbol u\in[0,1]^N}J(\boldsymbol u).$$

The reference uses two half-day price intervals. Target demand is generated
from the deterministic linear-response benchmark at prices `[0.72, 0.28]`
and point state $X_0=0.5$. Stochastic candidates use Beta(20,20) initial
uncertainty **and** process noise. Their price shift therefore reflects both
changes, not an experiment isolating process noise alone.

Pure FV supplies a deterministic objective. A coarse 5-by-5 price surface,
four low-cost starts and two reference starts initialize bounded Powell.
A dynamic M=30 mixture on 81 cells supplies a secondary optimizer; candidates
are reevaluated with pure FV and M=30/38 mixtures on 201 cells. MC validates
candidates afterward, not inside Powell.

Exact repeated candidate vectors may reuse a cached scalar within a single
multistart call. Prices are not rounded, tolerances are unchanged, and no
cache persists between optimization problems. Reusable matrix setup likewise
does not approximate the objective. Progress and solve counts are reported.

The returned best successful multistart result is a **numerical candidate**,
not a proof of global optimality. Successful termination of several starts
does not by itself show they found the same minimum; the objective spread is
now printed explicitly. The convex inner mixture QP does not make the outer
price problem convex.

Final candidate comparisons share initial samples and Wiener increments:

$$\Delta J^{(r)}=J^{(r)}(U_{\mathrm{det}})-J^{(r)}(U_{\mathrm{candidate}}),
\quad\operatorname{SE}(\overline{\Delta J})=s_{\Delta J}/\sqrt N.$$

A positive paired improvement supports a better decision for the tested
simulation. It does not establish absolute SDE-cost accuracy or global
optimality. In the original I run, FV and MC absolute costs differed by
roughly four percent even though both supported the improvement. That
remaining numerical discrepancy must not be described as sampling noise alone.

## Code ownership and execution

The BM-only reusable modules are now:

- `src/method/bm_1_mixture.py`: projected-mixture propagation;
- `src/method/bm_1_objective.py`: common demand grid, moments and costs;
- `src/method/bm_1_control.py`: FV/mixture evaluators and Powell.

Reference executables select cases, compare methods and create figures. Old
private helper imports were subsequently removed in the consolidation (see BM_GUIDE.md). Importing the EM/FV
demos or convergence module no longer runs simulations or saves graphs.
Shared WM/BM solvers and package initializers are unchanged. BM-only model
and validation files have compact formatting with the same executable AST. This includes the legacy `fokker_planc` spelling.

Run all regressions from the repository root:

```powershell
python -B -m unittest discover -s tests -v
```

Run any reference from the table, for example:

```powershell
python -B -m src.exe.run_model.bm_1.optimize stochastic
```

The full optimization reference is intentionally heavier than the unit tests.
It now prints stages and per-start/evaluation progress with immediate flushing.
Generated figures remain under the existing output paths. The reviewed
numerical defaults, random seeds, F1 APIs and solver recursions are retained.

## Sources and boundaries of the review

The canonical SDE convention follows F2-A and Junker et al. (2020),
DOI: 10.1016/j.apenergy.2020.115096. EM and strong/weak convergence terminology
follow Higham (2001), *An Algorithmic Introduction to Numerical Simulation of
Stochastic Differential Equations*, DOI: 10.1137/S0036144500378302.
The project-provided *Approximation of the Fokker-Planck Equation by Mixture
Distributions*, especially its static/dynamic constrained projection sections,
is the background for E–G. The variance identity, discrete conservation proof
and clarification of fixed-Hessian conditioning above are direct derivations
for the stated implementation conventions.

The original plan's CDF-integrated **basis**, independent projection schedule,
and complete separate FV/EM/sampling refinement study are not claimed as
implemented. They are distinct extensions, not changes silently introduced
under a cleanup. See the audit for the remaining shared-code limitations.

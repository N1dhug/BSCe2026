BM-F/G — aktuel filplan, fjerde gennemgang

Kun egne F/G-oprettelser med Git-evidens kan sammenlægges/fjernes. Blandet eller
ukendt ejerskab og149WM-afhængigheder bevares. Rådata/resultater er uændrede.

G: eksisterende g_weekday_backtest_adapter, bm_1_g_forecast og bm_1_g CLI
samler inputkontrakt og fører deklareret populationsbinding gennem eksport.
Eksisterende tests udvides; ingen ny manifestfiltype eller helperframework.
F: konkrete aktive sammenlægninger vælges efter ejerskab og caller/artefaktkort;
native matematik/grids/tolerancer og negative-inputguard bevares.
Fælleskalender: fjern evt. ubenyttet produktions-extension efter alle brugere
er håndteret; fit/scoring/identitetsgrænser og relevante tests bevares.
Struktur: reducer overlap i eksisterende docs/configs, flyt kun vores materiale,
fjern kun tomme, gennemsete mapper. Originalpakker/Git sikrer præcise gamle kilder.
README ejer brug, MATHEMATICS ejer model/data, COMPARISON ejer evidens/tællinger,
STATUS ejer checkpoints. Ingen nye permanente daterede delrapporter.

Baseline:26bdd15. Midlertidige ejerskabs-/filanalyser og testbudget i recovery/round4.
Gennemført filvis disposition føres her ved afslutning; ingen automatisk merge.
